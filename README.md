# Automated Excel Reporting Tool

## Problem
Businesses often receive raw Excel/CSV data that is incomplete and hard to analyze manually.

## Solution
This Python automation tool:
- Reads CSV/Excel files
- Cleans missing data using pandas
- Generates business summary metrics
- Exports reports to Excel and PDF

## Tech Stack
- Python
- pandas
- matplotlib
- fpdf

## How to Run
1. Clone repo
2. Install dependencies
3. Run `python main.py`

## Output
- Cleaned Excel file
- Summary Excel report
- PDF report
- Sales chart
